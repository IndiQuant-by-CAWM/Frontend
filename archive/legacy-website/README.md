# Legacy Website (Archived)

This folder holds the original static site (plain HTML/CSS/JS, three.js + GSAP
background) that used to live at the repo root. It is **not built or deployed
anymore** — the live site at [indiquantresearch.in](https://indiquantresearch.in)
is now the React/TanStack Start app in [`src/`](../../src), built via
`bun run build:pages` and deployed by
[`.github/workflows/deploy-pages.yml`](../../.github/workflows/deploy-pages.yml).

## Why it's here

Until 2026-07-29, GitHub Pages was configured to serve directly from the `main`
branch root (legacy branch-based Pages), so these files — not the React app —
were what actually served on the domain, regardless of the Actions workflow's
build output. The Pages source has since been switched to "GitHub Actions", so
the workflow build is now authoritative.

## Contents

- `index.html`, `careers.html`, `team.html` — legacy pages
- `styles/`, `scripts/` — legacy CSS/JS
- `images/` — legacy team photos
- `sitemap.xml`, `CNAME` — legacy site metadata (superseded by `public/CNAME`
  and the sitemap generated by the TanStack build)
- `google49b33b7b3350f08c.html` — Google Search Console verification file.
  A live copy is kept at [`public/google49b33b7b3350f08c.html`](../../public/google49b33b7b3350f08c.html)
  so domain verification keeps working under the new build.

Kept for reference only — do not wire this back into the build.
